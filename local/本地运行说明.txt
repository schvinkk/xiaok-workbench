小K万能工作台 · 本地离线版 使用说明
====================================

这是一个纯本地的求职/简历/投递追踪工具（Flask + SQLite），
不依赖任何云端、不联网也能用（除了首次装依赖需要联网一次）。
你的简历、投递记录全都存在本电脑的这个文件夹里，隐私可控。

----------------------------------------
一、第一次怎么跑起来（只看这一条就行）
----------------------------------------
1. 先装 Python（如果电脑上还没有）：
   去 https://www.python.org/downloads/ 下载安装，
   ⚠️ 安装时务必勾选 "Add Python to PATH"（加到环境变量）。
2. 双击本文件夹里的「一键启动.bat」。
3. 它会自动装好依赖，然后弹出黑色窗口并自动打开浏览器
   地址是：http://localhost:3000
4. 看到网页就成功了！开始用吧。

----------------------------------------
二、以后每次怎么用
----------------------------------------
直接双击「一键启动.bat」即可，不用重装依赖。
想关掉：把那个黑色窗口关掉就行（服务就停了）。

----------------------------------------
三、我的数据在哪 / 怎么备份 / 换电脑
----------------------------------------
所有数据在：本文件夹里的  data\app.db
备份：把这个文件夹整体复制一份就行。
换电脑：把整个文件夹拷到新电脑，双击「一键启动.bat」即可，
        数据会跟着走（前提是连 data 文件夹一起拷）。

----------------------------------------
四、如果启动报错（常见情况）
----------------------------------------
Q1. 提示"没检测到 Python"
A：没装或没勾 PATH。重装 Python 并勾选 Add Python to PATH。

Q2. 浏览器打不开 / 显示无法访问
A：等黑色窗口里的 "Running on http://0.0.0.0:3000" 出现后，
   再手动在浏览器输入 http://localhost:3000

Q3. 说端口 3000 被占用
A：关掉占用 3000 端口的程序；或右键编辑「一键启动.bat」，
   把 set PORT=3000 改成别的，比如 8080，保存后重跑。

Q4. 双击 bat 一闪而过
A：右键「一键启动.bat」→ 编辑，看是不是路径/Python 问题；
   或在文件夹地址栏输入 cmd 回车，再手敲 python app.py 看报错。

----------------------------------------
五、给会命令行的人（WSL / macOS / Linux）
----------------------------------------
cd 到这个文件夹
pip install -r requirements.txt
python app.py
# 打开 http://localhost:3000

----------------------------------------
六、功能一览
----------------------------------------
- 简历库：上传 PDF/Word 简历，自动解析姓名/技能/学历/专业
- 平台中心：BOSS/智联/拉勾/国聘等一键跳转搜索
- 职位看板：收藏/屏蔽/一键投递（带每日上限与去重）
- 智能匹配：简历 vs 职位要求，给出匹配度与差距
- 投递追踪：看板拖拽改状态 + 统计 + 待跟进提醒 + 手动补录
- 计划打卡 / 时间线 / 考试政策 / 残疾人通道 / 设置
