# 小K万能工作台 · 单文件版 — 使用说明

面向云贵川桂的求职 / 备考一体化工作台。整个应用就是**一个 HTML 文件**，打开即用，不需要装任何东西。

---

## 一、分享与部署

本单文件版设计为**自托管**：把 `index.html` 部署到你自己的静态托管（GitHub Pages / EdgeOne / CloudStudio / Nginx 等），再把地址发给需要的人即可。

> 本项目为开源模板，**不提供官方在线地址**。请部署你自己的实例——链接归属你自己，数据也只存在访问者各自的浏览器里，互不干扰。

**离线用法**：直接把 `index.html` 发给对方，双击就能打开，断网也能用。

---

## 二、加到手机桌面当 APP 用

**iPhone（Safari）**
1. Safari 打开你部署的链接
2. 点底部「分享」按钮
3. 下滑选「添加到主屏幕」
4. 桌面上就多了一个图标，点开是全屏的，跟 APP 一样

**安卓（Chrome / 夸克 / 浏览器）**
1. 浏览器打开你部署的链接
2. 点右上角菜单
3. 选「添加到主屏幕」或「添加到桌面」

---

## 三、隐私说明（重要，转发时也说一下）

- 所有数据存在**每个人自己浏览器的 localStorage 里**，不上传服务器。
- 你和别人打开的是同一个链接，但**数据完全隔离**，互相看不到。
- 简历解析、职位匹配、计划生成，全部在本地浏览器里跑完，不联网。
- 反过来说：**清浏览器缓存 / 换手机 / 换浏览器 = 数据没了**，所以要定期导出备份。
- 链接是公开的，任何人拿到都能打开，所以**不要在这个页面里存身份证号、银行卡这类信息**。

## 四、数据备份（务必看）

右上角两个按钮：

| 按钮 | 作用 |
|------|------|
| 备份 | 导出一个 JSON 文件，存到网盘或发给自己 |
| 恢复 | 选中之前导出的 JSON，一键还原全部数据 |

数据积累到 30 条时，页面顶部会自动弹一条黄色提醒让你备份。换手机就是：老手机导出 → 文件传过去 → 新手机导入。

## 五、11 个功能模块

### 1. 首页
- **今天要处理**：逾期任务标红，可以直接「完成」或「推迟1天」；待跟进的投递可以「已跟进」或「明天再说」。昨天没做完的任务不会消失，会一直挂在今天。
- 四省风向标：云贵川桂 28 个热门行业，点省份切换。
- 4 张数据卡：投递记录 / 收藏职位 / 进行中计划 / 临近节点。

### 2. 简历解析
粘贴简历文本（或选 .txt / .md 文件），自动提取：专业、学历、手机、邮箱、技能关键词，并给一个完整度评分。全程本地运行。

### 3. 平台直达
18 个招聘平台（BOSS直聘、智联、猎聘、58、国聘、鱼泡、中国国家人才网、各省人事考试网等），输一个关键词，一键生成带城市参数的搜索链接批量打开。搜索模板可以自己改。

### 4. 职位库
32 条云贵川桂真实岗位样例 + 支持手动添加 / 批量导入（用 `|` 分隔）。可筛选、收藏、投递、拉黑、批量投递。

### 5. 投递看板
6 个状态：待投递 → 已投递 → 已查看 → 面试 → Offer → 未通过。左右箭头推进状态，可加跟进备注和提醒日期。

### 6. 计划打卡
输入目标（比如「中药士资格考试」「考研上岸」「教师资格证」），自动识别赛道并生成分阶段任务和排期。支持每日打卡、连续天数统计、任务增删。

### 7. 智能匹配
拿你的简历跟职位库逐条打分（0-100），算法：技能命中 + 领域桥接 + 核心专业加权。点单条可以看匹配明细：命中了什么、缺什么。

### 8. 时间线
15 个关键节点（国考、省考、教资、考研、四六级等）的时间提醒，7 天内的会推到首页。

### 9. 考试目录
四赛道考试信息速查。

### 10. 政策与权益
残疾人就业、基层就业、三支一扶等政策入口。

### 11. 设置
个人画像（省份 / 城市 / 目标岗位 / 学历 / 专业 / 关键词）、示例数据恢复与清空、清空我的数据。

## 六、示例数据

首次打开会自带：1 份示例简历（中药学）、1 个示例备考计划（含 1 条逾期任务）、1 条逾期待跟进的投递、32 个职位、15 个时间节点。

设置页里有「清空示例数据」按钮，清掉不影响你自己录入的内容。

## 七、文件结构

```
小K工作台-单文件版/
├── index.html      主文件（约 122KB，全部内联，零外部依赖）
├── dist/
│   └── index.html  部署用副本
├── tests/          jsdom 自动化测试脚本
└── 使用说明.md
```

要改功能，直接改 `index.html`，改完把 `dist/index.html` 同步覆盖再重新部署。

## 八、已知说明

- 托管平台（CloudStudio）会在页面里注入一个腾讯统计脚本，这不是工作台自身的代码，不影响任何功能，本体依然是零依赖的。
- 沙箱链接长期不访问可能被回收，届时重新部署即可拿到新链接。需要永久固定域名的话可以后续绑自有域名。
